## AM Movies

Aplicação web desenvolvida com React que consome a API da TMDB para exibir filmes e séries populares, detalhes completos, trailers oficiais e conteúdos similares.

Projeto desenvolvido com foco em componentização, organização de código e experiência do usuário.

## Tecnologias Utilizadas

- React
- Vite
- Styled Components
- React Router DOM
- TMDB API
- Intersection Observer API
- JavaScript (ES6+)

---

## Funcionalidades

-  Página inicial dinâmica com destaque
-  Página de Filmes
-  Página de Séries
-  Página de Detalhes
-  Trailer incorporado via YouTube
-  Conteúdos similares
-  Busca de filmes e séries
-  Animações suaves
-  Layout totalmente responsivo
